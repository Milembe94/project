## Problem Identification (ATM Management System)

Describe the problem
Many people need a secure and simple way to manage their bank accounts.
Traditional manual systems are slow, can cause errors, and make it difficult for users to access banking services quickly.
This ATM Management System was developed to help users perform banking operations such as:

-Login
-Check balance
-Deposit money
-Withdraw money
-Transfer money
-Change PIN
-View mini statement

## The system stores customer information and transaction history digitally for easier management

## The following people are affected by this problem:

-Bank customers who need fast banking services
-Bank employees who manage customer transactions
-Organizations that still use manual record systems

## Without an automated ATM system:

-transactions become slow,
-records may be lost,
-and errors can occur frequently

## This problem should be solved because:

-It improves security using PIN authentication
-It saves time for customers and banks
-It reduces human errors
-It keeps transaction records safely
-It allows users to access banking services easily
-It improves efficiency in financial management

## The ATM system provides a modern and reliable way to manage banking operations.
